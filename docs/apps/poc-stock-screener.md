# 📈 PoC Specification: Stock Screener & Compare Lab

> **경로**: `apps/poc-stock-screener`  
> **서브 경로**: `/make/poc-stock-screener/`  
> **기술 스택**: Vite, React 19, Tailwind CSS, Recharts, Lucide React  
> **반응형 원칙**: Mobile Summary Card View & Desktop Financial Table

---

## 1. 개요 및 목적
* 미국장(S&P 500/나스닥) 및 국내장(KOSPI/코스닥) 우량주 데이터를 기반으로, 초보자부터 전문 투자자까지 검증된 투자 전략에 맞춰 종목을 원클릭 발굴하고 1:1 맞대결 비교할 수 있는 **스마트 주식 스크리너 & 비교 분석 랩**입니다.
* 정적 사이트(Client-Only) 환경에서 고품질 내장 데이터 스냅샷을 활용하여 0.01초 만에 즉각적인 필터링과 인터랙티브 차트 렌더링을 제공합니다.

## 2. 4대 투자 전략 추천 프레임워크 (One-Click Presets)

사용자가 복잡한 재무 지표를 몰라도 검증된 전략 버튼 하나로 종목을 필터링합니다:

| 전략 | 투자 철학 | 핵심 발굴 요건 | 대표 종목 예시 |
| :--- | :--- | :--- | :--- |
| **👑 워런 버핏 우량주** | 불황에도 독점력과 현금 창출력으로 돈을 잘 버는 해자 기업 | • ROE(자기자본이익률) ≥ 15%<br>• 영업이익률 ≥ 15%<br>• 부채비율 ≤ 100% | 애플(AAPL), 마이크로소프트(MSFT), 삼성전자 |
| **🚀 미래 고성장주** | 시장 예상치를 뛰어넘는 이익 폭발과 미래 가치를 지닌 주도주 | • 차기 예상 이익 성장률 ≥ +25%<br>• 목표주가 괴리율(Upside) ≥ +20%<br>• PEG ≤ 1.5 | 엔비디아(NVDA), 브로드컴(AVGO), SK하이닉스 |
| **📈 추세 모멘텀주** | 시장 자금이 쏠리며 52주 신고가를 돌파하는 강한 상승 탄력주 | • 3개월 주가 상승률 시장 상회<br>• 52주 최고가 대비 -10% 이내<br>• 단기/중기/장기 이평선 정배열 | 메타(META), 일라이릴리(LLY), 삼양식품 |
| **🛡️ 고배당 캐시카우** | 주가 하락장에서도 든든한 현금 배당을 쥐여주는 방어 가치주 | • 배당수익률 ≥ 4.0% ~ 7.0%<br>• 지속 가능한 배당성향 (20~60%) | 코카콜라(KO), JP모건(JPM), KB금융 |

## 3. 핵심 기능 및 차별화 UX 명세

### 3.1 듀얼 시장 지원 (Market Selector)
* 상단 토글로 **`[🇺🇸 미국장 S&P500/나스닥]`**과 **`[🇰🇷 국내장 KOSPI/코스닥]`**을 1클릭 전환.
* 통화 자동 대응: 미국장(USD `$`), 국내장(KRW `₩`).

### 3.2 추천 사유 한 줄 요약 (Reasoning Tag 💡)
* 각 종목 카드마다 초보자가 직관적으로 이해할 수 있는 추천 이유 문장 제공.
  * 예: *"ROE가 45%로 자본 효율이 극상이며 부채비율이 30%로 재무가 극도로 탄탄합니다."*

### 3.3 1:1 맞대결 비교 분석 (Compare Drawer & Scorecard ⚖️)
* 종목 리스트에서 최대 2개 종목을 체크하면 하단에 맞대결 패널 팝업:
  * **기준 100 정규화 수익률 궤적 차트 (Recharts)**: 주가가 다른 두 주식의 3M/6M/1Y 상대 수익률 궤적을 100 기준으로 오버레이 비교.
  * **투자 매력도 스코어카드**: 성장성, 수익성, 밸류에이션, 배당 부문별 승자 판정 뱃지 제공.

### 3.4 모바일 카드 뷰 vs 데스크톱 재무 테이블 📱
* **데스크톱 (≥768px)**: 주가, 3개월/1년 수익률, 선행 PER, ROE, 배당률을 한눈에 보는 풀 테이블.
* **모바일 (<768px)**: 핵심 3개 지표와 전략 뱃지가 강조된 '스마트 요약 카드' 그리드.

## 4. 컴포넌트 분리 아키텍처 (Strict Conventions) 🏛️

모노레포의 공통 컴포넌트 아키텍처 규칙에 따라 모듈을 엄격히 분리합니다:

```text
apps/poc-stock-screener/src/
├── components/
│   ├── layout/
│   │   ├── Header.jsx           # 상단 포털 복귀 및 타이틀
│   │   └── MarketSelector.jsx   # 미국/국내 시장 전환 탭
│   ├── strategy/
│   │   ├── StrategyBar.jsx      # 4대 추천 전략 필터 탭 바
│   │   └── StrategyBadge.jsx    # 종목별 전략 부합 뱃지
│   ├── stocks/
│   │   ├── StockList.jsx        # 반응형 카드/테이블 뷰 스위처
│   │   ├── StockCard.jsx        # 모바일 전용 요약 카드
│   │   ├── StockTable.jsx       # 데스크톱 전용 재무 테이블
│   │   └── MetricBadge.jsx      # 수치 포맷 및 상승/하락 컬러 표시
│   └── compare/
│       ├── CompareDrawer.jsx    # 하단 1:1 맞대결 슬라이드 패널
│       ├── ScoreCard.jsx        # 분야별 승패 판정 스코어카드
│       └── ReturnLineChart.jsx  # Recharts 기반 기준 100 정규화 수익률 라인 차트
├── hooks/
│   ├── useStockData.js          # 시장별 데이터 로드 및 정제 훅
│   ├── useStockFilter.js        # 전략 프리셋 및 검색 필터링 훅
│   └── useStockCompare.js       # 2개 종목 비교 선택 및 스코어 계산 훅
├── utils/
│   ├── formatters.js            # 통화($/₩), 퍼센트(+15.2%), 배율(25.4배) 포맷터
│   └── strategies.js            # 4대 전략 판정 알고리즘 및 추천 사유 생성 함수
├── data/
│   ├── stocks-us.json           # 미국장 30개 우량주 데이터셋
│   └── stocks-kr.json           # 국내장 30개 우량주 데이터셋
├── App.jsx                      # 컴포넌트 조립 루트 (< 120줄 제한)
└── main.jsx
```

## 5. 차후 확장 개발 로드맵 (Phase 2)
1. **커스텀 필터 슬라이더 빌더**: 사용자가 직접 PER, ROE, 3개월 상승률 수치를 슬라이더로 조절.
2. **나만의 전략 저장 (My Strategy)**: 커스텀 필터 조건을 `localStorage`에 영구 보존.
3. **실시간 API 연동 모드**: 사용자 개인 API Key를 입력받아 실시간 호가/컨센서스 업데이트.
