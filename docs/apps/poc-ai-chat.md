# 🤖 PoC Specification: AI Chat Interface

> **경로**: `apps/poc-ai-chat`  
> **서브 경로**: `/make/poc-ai-chat/`  
> **기술 스택**: Vite, React, Tailwind CSS  
> **반응형 원칙**: Mobile Viewport & Virtual Keyboard Optimized

---

## 1. 개요 및 목적
* LLM 또는 챗봇 인터랙션을 위한 **대화형 UI 샌드박스**입니다.
* 실제 API 연동뿐만 아니라 Mock 데이터 기반의 글자 단위 스트리밍 텍스트 렌더링, 메시지 버블 인터랙션, 코드 블록 복사 등을 실험합니다.

---

## 2. 주요 실험(PoC) 및 모바일 최적화 항목

1. **타이핑 스트리밍 효과 (Typing Effect / Streaming)**:
   * 토큰 단위로 실시간으로 텍스트가 타이핑되는 애니메이션 및 렌더링 성능 검증
2. **모바일 가상 키보드 및 뷰포트 대응 (핵심 📱)**:
   * 모바일 브라우저에서 하단 입력창을 탭했을 때 가상 키보드가 팝업되어도 입력창이 화면 밖으로 밀려나지 않도록 `dvh`(동적 뷰포트 높이) 및 `visualViewport` API 적용
   * 메시지 영역 자동 최하단 스크롤(Auto Scroll to Bottom) 보장
3. **코드 블록 및 마크다운 메시지**:
   * 답변 내 마크다운 문법(코드 하이라이팅, 볼드, 리스트) 실시간 파싱
   * 모바일 화면에서 긴 코드가 표시될 때 가로 스크롤 및 원터치 '복사' 버튼 제공
4. **대화 컨트롤 및 툴바**:
   * 모바일에서는 모델 선택 및 설정 메뉴를 바텀 시트(Bottom Sheet)나 드롭다운으로 축약
   * 시스템 프롬프트(Persona) 변경 기능
   * 대화 기록 초기화 및 로컬 스토리지 자동 저장
5. **허브 복귀 네비게이션**:
   * 상단 네비게이션 바에 메인 포털(`/make/`) 복귀 버튼 상시 고정

---
