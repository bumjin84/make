# 🤖 PoC Specification: AI Chat Interface (Multi-Session & Gemini Live)

> **경로**: `apps/poc-ai-chat`  
> **서브 경로**: `/make/poc-ai-chat/`  
> **기술 스택**: Vite, React, Tailwind CSS, Google Gemini REST API  
> **반응형 원칙**: Mobile Viewport & Virtual Keyboard Optimized

---

## 1. 개요 및 목적
* 사용자가 여러 개의 독립된 **대화 세션(채팅방)**을 개설하고 자유롭게 오갈 수 있는 **멀티 세션 대화형 AI 샌드박스**입니다.
* 각 세션은 독립된 문맥(Context)을 가지며, 해당 세션의 대화 내역만 LLM(Gemini)에 전달됩니다.

---

## 2. 주요 기능 및 UI 인터랙션 명세

### 2.1 멀티 세션 관리 (Multi-Session Management) 💬
* **`[+ 새 대화 시작 (New Chat)]`**:
  * 클릭 시 완전히 새로운 독립 세션 생성
  * 사용자가 첫 질문을 입력하면 질문 첫 줄을 기반으로 대화방 제목 자동 지정
* **사이드바 세션 목록**:
  * 생성된 대화방 목록 표시 (최근 대화순 정렬)
  * 활성 세션 하이라이트
  * 대화방 개별 삭제(`🗑️`) 버튼 제공
* **반응형 사이드바**:
  * 데스크톱: 좌측 고정 / 접기 토글 패널
  * 모바일: 좌측 상단 햄버거 메뉴(`☰`)를 통한 슬라이드 드로어(Drawer)

### 2.2 API Key 관리 및 UI 배치 🔑
* **헤더 및 입력창 통합 접근**:
  * 헤더 우측 상태 뱃지 (`⚪ Mock Mode` / `🟢 Gemini 2.5 Live`)
  * 채팅 입력창 좌측의 퀵 `[🔑]` 버튼
* **API Key 설정 모달**:
  * Key 입력, 비밀번호 마스킹/보기 토글, 무료 키 발급 링크
  * 키 삭제 시 Mock 모드 자동 전환
  * 키 변경 시 기존 세션 초기화 여부 확인 모달 제공

### 2.3 실시간 SSE 스트리밍 & 슬라이딩 윈도우 ⚡
* **독립 컨텍스트 전달**:
  * 질문 전송 시 **현재 활성화된 세션의 대화 내역만** `contents` 배열로 Gemini API에 전달
* **슬라이딩 윈도우**: 각 세션당 최신 30개 메시지 롤링 유지로 렌더링 성능 및 토큰 비용 최적화
* **SSE 스트리밍**: `gemini-2.5-flash` 모델로부터 실시간 타이핑 스트리밍 수신
