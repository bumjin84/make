# 📝 PoC Specification: Markdown Studio (Theme & Export Lab)

> **경로**: `apps/poc-markdown`  
> **서브 경로**: `/make/poc-markdown/`  
> **기술 스택**: Vite, Vanilla JS, Marked.js  
> **반응형 원칙**: Adaptive Split/Tab Layout & Responsive Toolbar

---

## 1. 개요 및 목적
* 브라우저에서 마크다운을 실시간 편집하고 다양한 테마 스타일을 즉각 적용할 수 있는 **스마트 마크다운 스튜디오**입니다.
* 작성한 문서를 원본 `.md` 파일 및 스타일이 완전히 내장된 단독 실행형 `.html` 파일로 내보낼 수 있습니다.

---

## 2. 주요 기능 및 UI 인터랙션 명세

### 2.1 멀티 테마 스타일 스위처 (Themes) 🎨
* **GitHub Dark (기본)**: 짙은 슬레이트 배경, 에메랄드/스카이블루 포인트
* **GitHub Light**: 화이트 배경, 깃허브 공식 라이트 스타일
* **Notion Clean**: 오프화이트 배경, 여백이 돋보이는 미니멀 스타일
* **Academic Sepia**: 따뜻한 미색 배경과 Serif(명조체) 타이포그래피

### 2.2 다채로운 내보내기 (Export Suite) 📥
* **Download Markdown (`.md`)**: 현재 에디터 내용 그대로 텍스트 파일 저장
* **Download Standalone HTML (`.html`)**:
  * 선택된 테마의 전체 CSS가 `<style>`로 인라인 내장된 독립 HTML 파일 생성
  * 어디서 열든 인터넷 연결 없이 동일한 비주얼 렌더링 보장
* **Copy HTML**: 렌더링된 HTML 소스를 클립보드에 원클릭 복사

### 2.3 적응형 레이아웃 및 모바일 대응 📱
* **데스크톱 (≥768px)**: 2열 나란한 스플릿 뷰 (에디터 ↔ 실시간 미리보기)
* **모바일 (<768px)**: 상단 `[에디터 | 미리보기]` 탭 토글 모드로 자동 적응
* 상단 툴바에 테마 선택 및 내보내기 버튼 컴팩트 정렬
