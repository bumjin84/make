# 📝 PoC Specification: Markdown Studio

> **경로**: `apps/poc-markdown`  
> **서브 경로**: `/make/poc-markdown/`  
> **기술 스택**: Vite, Vanilla JS, Marked.js, Highlight.js  
> **반응형 원칙**: Adaptive Split/Tab Layout

---

## 1. 개요 및 목적
* 브라우저에서 마크다운 텍스트를 작성하고 실시간으로 파싱 결과를 미리보는 **실시간 마크다운 스튜디오/뷰어**입니다.
* 데스크톱과 모바일의 화면 크기 차이를 감안하여 적응형 레이아웃을 제공합니다.

---

## 2. 주요 실험(PoC) 및 반응형 레이아웃 전환 (핵심 📱)

1. **화면 너비에 따른 적응형 레이아웃 (Adaptive Layout)**:
   * **데스크톱 (>= 768px)**: 좌측(에디터)과 우측(미리보기)이 동시에 보이는 **스플릿 뷰(Split View)**
   * **모바일 (< 768px)**: 좁은 폭에서 2분할 시 가독성이 떨어지므로 상단에 **[에디터 | 미리보기] 탭 토글 버튼**을 제공하여 1개 화면씩 전환
2. **코드 구문 강조 (Syntax Highlighting) 및 모바일 가로 스크롤**:
   * 코드 블록이 모바일 화면 폭을 넘을 때 줄바꿈이 깨지지 않고 자연스럽게 가로 스크롤되도록 스타일링
3. **GFM(GitHub Flavored Markdown) 지원**:
   * 체크리스트(`- [x]`), 테이블, 알림창 렌더링
   * 모바일 테이블 렌더링 시 가로 스크롤 래퍼 자동 감싸기
4. **내보내기 기능**:
   * 작성한 내용을 `.md` 파일 다운로드 또는 HTML 클립보드 복사
5. **허브 복귀 네비게이션**:
   * 상단 헤더의 버튼으로 메인 포털(`/make/`) 복귀

---

## 3. UI 레이아웃 설계 (데스크톱 vs 모바일)

```
[ 데스크톱: 2열 스플릿 뷰 ]
+-------------------------------------------------------+
| [< Portal]   Markdown Studio     [Export] [Copy]      |
+---------------------------+---------------------------+
| Raw Editor                | Preview                   |
| # Header                  | # Header                  |
+---------------------------+---------------------------+

[ 모바일: 상단 탭 전환 뷰 ]
+-------------------------+
| [< Portal]    [Export]  |
+-------------------------+
| [ 에디터 ]  | *(미리보기)*| <- 탭 선택 토글
+-------------------------+
| (선택된 화면 전체 표시) |
| # Header                |
| - [x] 모바일 대응 완료  |
|                         |
+-------------------------+
```
