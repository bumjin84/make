# 🎨 PoC Specification: 3D Scene Lab

> **경로**: `apps/poc-3d-scene`  
> **서브 경로**: `/make/poc-3d-scene/`  
> **기술 스택**: Vite, Vanilla Three.js (or React Three Fiber), Canvas API  
> **반응형 원칙**: Touch-Ready WebGL Canvas

---

## 1. 개요 및 목적
* 웹 브라우저 환경에서 **WebGL 기반의 3D 그래픽과 물리 인터랙션**을 가볍게 실험하는 샌드박스입니다.
* 데스크톱 마우스 조작뿐만 아니라 모바일 터치 제스처를 완벽하게 지원합니다.

---

## 2. 주요 실험(PoC) 및 모바일/반응형 최적화

1. **터치 제스처 대응 (Mobile Touch Controls 📱)**:
   * **1점 터치 드래그**: 360도 카메라 궤도 회전 (Orbit)
   * **2점 터치 핀치(Pinch)**: 부드러운 줌 인/아웃
   * **2점 터치 드래그**: 카메라 팬(Pan) 이동
2. **동적 캔버스 리사이징 (Dynamic Resize)**:
   * 모바일 기기 회전(가로/세로 전환) 및 윈도우 창 크기 변경 시 화면 왜곡 없이 카메라 종횡비(Aspect Ratio) 자동 재계산
   * 고해상도 모바일 디스플레이(Retina, 모바일 DPR 2~3) 최적화로 배터리 소모 및 발열 방지 (`renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`)
3. **접이식 컨트롤 패널 (Collapsible GUI)**:
   * 데스크톱: 우측 상단 고정 패널
   * 모바일: 화면을 가리지 않도록 하단 플로팅 접이식 토글 서랍(Drawer) 형태
4. **허브 복귀 네비게이션**:
   * 좌측 상단 플로팅 버튼으로 메인 포털(`/make/`) 복귀
